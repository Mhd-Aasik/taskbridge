# Instrument Sans

Unmodified upright variable Instrument Sans from the official Google Fonts
catalogue, downloaded 24 October 2026:
https://github.com/google/fonts/tree/main/ofl/instrumentsans

Source filename: `InstrumentSans[wdth,wght].ttf`. The local filename is descriptive;
the font's internal family name is unchanged. The same normal 400–700 weights
used by TaskBridge are served through Vite with `font-display: swap`, without an
external stylesheet or speculative font preload. The default width is retained.
